Gomoku AI Extension

欢迎使用 VS Code 五子棋插件。这是一个集成了 Git 版本控制概念的策略游戏。

🎮 游戏规则

  • 目标 率先连成5子获胜。
  • 机制 每位玩家每 2回合 自动获得一个随机技能。
  • 限制 手牌上限为 3 张。

🛠️ 技能 (Skills)

1. 飞沙走石 (Git Revert)

移除对方一颗棋子，并将该位置标记为虚空 (Void)，封锁无法落子。

2. 再来一次 (Double Commit)

本回合可以连续落下两颗棋子。

3. 两极反转 (Git Rebase)

打乱棋盘上所有棋子的位置（保留数量），跳过你的本回合。

4. 一忘皆空 (Git Reset --hard)

清空对方所有手牌，对方会随机落下等量的棋子，跳过你的本回合。。

5. 擒拿擒拿 (Code Injection)

随机在棋盘空位生成 4 颗己方棋子，跳过你的本回合。
